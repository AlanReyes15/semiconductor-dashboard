# Semiconductor Water and Emissions

Team H dashboard for the Climate-Feature Dashboard for Semiconductor Technology project.
Jamey Cline, Alan Reyes-Navarrete, Nathaniel Wilgen.

Open the live page through GitHub Pages. The "Manipulated version" is a classroom simulation and its numbers are altered on purpose.

Main data: Frost and Hua (2019), global semiconductor water withdrawals, Purdue University Research Repository.
